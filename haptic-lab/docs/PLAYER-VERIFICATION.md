## 画面と保存データ

音楽中心のホーム、2つの下部タブ、右上のメニュー、振動調整・タッチパッド・使い方への移動を確認しました。URLキーボード表示中に下部ナビゲーションの位置が変わらず、キーボードの背後へ隠れることを座標と画像で確認しています。

初回の作成・保存、再起動後の保存済み再生、停止、個別削除を確認しました。再生前から波形のデータが表示されること、周波数表示への切り替え、オーケストラ向け選択をテスト・目視確認しました。13枚の画面画像を `dist/preview/` へ保存します。

波形は短いタップも集約し、強さ・低音・モード・密度・同期補正を反映します。フーリエ表示は保存した振動の強弱の変化（0.4〜25 Hz）で、音声スペクトルやモーターの実測周波数ではありません。既知の周期、一定値、無音、設定変更を検証しています。

オーケストラ向けは自然な強弱と打音の位置を保持し、持続をなめらかにしてタップを間引きます。固定テンポの拍は加えません。クレッシェンドと無音の保持を単体テストで確認しました。旧版の振動・曲データの読み込みと、PCの10 ms間隔のデータから `CHHapticPattern` を作れることも検証しています。

## PC解析とYouTube URL

実音源のデコード、左右逆位相の低音、無音・不正サンプル、キャッシュの再利用・読み直し、1曲だけの削除、認証、解析待ち・解析中のキャンセル、一時音源の除去、サーバー停止を確認しました。

Core i5-11400F、Python 3.13.14、NumPy 2.5.3、imageio-ffmpeg 0.6.0、yt-dlp 2026.8.19で測定しています。GPUは使いません。

| 入力 | 測定した処理 | 所要時間 |
| --- | --- | --- |
| 同梱12秒サンプル | デコード・解析・保存 | 約0.42秒 |
| 180秒の試験信号 | 解析のみ | 約3.6秒 |
| 公開YouTube動画213.06秒 | URLから取得・解析・保存 | 約8.0秒 |

YouTubeでは `dQw4w9WgXcQ` の公開動画を使い、動画URLだけで完了しました。一時音源は削除しています。ログイン・非公開動画・ライブ・年齢制限の取得は確認していません。yt-dlpの取得は公式APIの機能ではなく、動画の制限やサービス側の変更で失敗する場合があります。

時間はこのPCでの測定値です。待ち時間・iPhoneへの転送は含まず、通信速度や曲の内容で変わります。SE3実機の解析時間は未計測です。PCの44.1 kHz / 4096 FFT / 10 msとiPhoneの22.05 kHz / 1024 FFT / 20 msを選べます。触感の良さは実機で比較してください。
