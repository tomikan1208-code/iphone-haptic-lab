# 音楽と振動を再生する

ResonはiOS 16以降のCore Haptics対応iPhoneで、音楽と振動を同期させる。新規作成と作り直しでは、iPhoneの帯域別精密解析かPCの音楽AI編曲を選び、確認後に開始する。作成後は振動をiPhoneに保存する。再生時はPC不要だが、YouTubeや直接URLの音楽再生には通信が必要。[PCの準備](PC-SERVER.md)。

この手順はソース版2.8.4の操作に対応する。Xcodeビルドとテスト結果は配布物のBUILD-INFO.jsonとTEST-SUMMARY.jsonを参照。iPhone実機の触感は未確認。[変更と検証](verification/SERENADE.md)。

## 最初の1曲

1. PCのAI編曲を使う場合は `Start-PCServer.bat` でサーバーを起動し、iPhoneと同じWi-Fiへ接続する。iPhoneの精密解析ではこの準備は不要。
2. AI編曲の場合は右上「… → 解析方法・PCサーバー」で、PCが表示したHTTP URLと接続キーを入力し、「設定を保存」「接続を確認」を押す。
3. 下部バーの「検索」で曲名・アーティスト名・チャンネル名を入力し、動画を選ぶ。動画URLや音源の直接HTTPS URLも貼り付けられる。
4. 必ず開く確認画面で「iPhoneで精密解析」か「PCでAI編曲」を選ぶ。iPhoneの場合は「音に追従」「リズム中心」も選べる。どちらも標準／オーケストラ向けを選べる。高速解析は使えない。音源ファイルを選んだ場合も、その後に作成ボタンを押すまで解析は開始しない。
5. 作成ボタンを押すと取得・解析・保存が進む。完成したら再生する。次回は「再生リスト → 作成済み」から保存した振動を使う。

作成中は進捗とキャンセルを表示する。「一覧に戻る」で閉じても下部の「振動を作成中」から戻れる。アプリをバックグラウンドへ移すと作成をキャンセルする。失敗・キャンセルした途中の振動は保存リストへ入らない。AI環境が未設定の場合はPCの設定エラーを表示する。

## 曲の展開と触感の調整

新しい編曲データの再生画面には、メロ・サビ・間奏・展開の推定と振動のモチーフ系統を表示する。区間ボタンでその時刻へ移動できる。区間名はAIの推定で、手動で確認した正解ラベルではない。

初期表示は実際の編曲強度の「波形」。前後2秒の持続とアクセントを表示する。「周波数」へ切り替えると元音の参考スペクトルを表示する。新しい編曲は音の帯域をそのまま振動へ変換していないため、参考スペクトルに振動の帯域を重ねない。

動画は全画面の再生画面で、画面幅いっぱいの16:9表示にする。上部の「再生中」バーと停止用の四角いボタン、再生画面下部の全体強度スライダーは表示しない。一時停止・再開は中央の再生ボタンを使う。

縦画面では動画・曲名・動画下の操作バーを上へスワイプすると横向き全画面になる。iPhoneを横へ回しても切り替わる。横画面では下へスワイプ、縦へ回す、または「縦画面に戻す」ボタンで戻る。縦画面の下スワイプと「閉じる」は最小化する。YouTube動画は最小化中も映像を表示し続け、再生位置・一時停止状態を保持する。ミニプレイヤーの曲名で開き直せる。「×」は再生を終了する。

動画の下の「振動を調整」で、「全体の強さ」（0〜400%）、持続・瞬間の強さ、瞬間の鋭さ、ビート密度を変更し、曲ごとに保存する。詳細設定では「編曲」「アクセント」「持続」を選べる。編曲済みの持続強度を使うので、旧方式の低音量スライダーは表示しない。100%を超える増幅も各プレーヤーの最大値まで。

標準の再生調整値は次のとおり。100%は保存した強さの等倍で、常に端末の最大出力になる意味ではない。編曲データは再生調整と独立して保存し、調整時に再解析する必要はない。

| 設定 | 標準値 |
| --- | --- |
| モード | ミックス。AI編曲では「編曲」 |
| 全体の強さ | 70% |
| 持続振動 | 100% |
| 瞬間振動 | 100% |
| 瞬間の鋭さ | 50%。記録された鋭さを保つ |
| ビートの密度 | 70% |
| 同期の補正 | 0 ms |
| 低音の量 | 65%。iPhone解析用。AI編曲は持続振動で調整 |

右上「… → グローバル振動設定」で全曲に共通の値を編集する。グローバル設定を使う曲には、変更が自動反映される。曲の再生画面で調整すると、その曲だけの個別設定として保存し、グローバル設定を変更しても個別の値を保つ。

曲の「振動を調整 → グローバルに戻す」はワンボタンで個別設定を解除する。その時点の値へ戻すだけでなく、以降のグローバル変更にも追従する。「この調整をグローバルにする」は現在の個別値を共通設定にし、この曲もグローバルへ戻す。他の曲の個別設定は保持する。

グローバル画面の「標準値に戻す」は共通値を上表へ戻す。グローバル・個別のどちらも再起動後に保持する。旧版で標準値から変更した曲は個別設定を引き継ぎ、標準値の曲はグローバルを使う。振動を作り直しても設定の選択と個別値を引き継ぐ。

以前のversion 1 / 2の保存データは引き続き再生できる。旧データの周波数表示と調整項目も保持する。新方式へ追加する場合は、その曲の「… → 別の解析を追加」を選ぶ。モデルや設定の変更だけでは、iPhoneにある既存データを書き換えない。

## 解析結果を比較する

同じ曲に複数の解析結果を保存できる。「別の解析を追加」で解析方法・作り方・仕上げを確認して作成する。以前の振動は削除せず、新しい結果を追加する。同じ方法・設定で追加しても再解析し、別の結果として保存する。PCにも結果ごとに独立したIDで振動・グラフ・スコア・AHAPを保存する。

作成が完了しても、表示中のタブ・再生リストを変更しない。元のリストで次の曲を選べる。「作成済み」は自分で開いたときだけ表示する。

YouTube動画内の操作バー・全画面ボタン・アノテーションは埋め込み設定で非表示にし、再生・停止・シークはアプリ下部の操作を使う。字幕を強制表示する設定を付けず、プレーヤーが対応していれば字幕モジュールを準備時・再生状態変更時・モジュール追加時に解除する。アプリを終了した後も、新しいプレーヤーでこの処理を実行する。字幕モジュールの解除は非公開機能のため、YouTube側の変更で効かない場合がある。動画に焼き込まれた文字は消せない。

開始前・一時停止中の再生マークやタイトル、終了時の関連動画、YouTubeロゴは完全には非表示にできない。関連動画は同じチャンネルに限定する。画質指定APIは廃止されているため、1080pを上限とする最高画質の固定・復元は実装できない。画質はYouTubeが回線・端末・表示サイズなどに応じて自動選択する。[表示パラメータ](https://developers.google.com/youtube/player_parameters)、[画質指定APIの廃止](https://developers.google.com/youtube/iframe_api_revision_history#october-24,-2019)。

再生画面の「振動を調整 → 解析方法の切り替え」から、iPhone／PC、作り方、仕上げ、作成日時を見て選ぶ。音楽を再読み込みせず、再生位置を保って振動だけを切り替える。最後に選んだ結果を保存し、次回の再生・再起動後も使う。追加した直後は新しい結果を選択する。触感の個別・グローバル設定は曲単位で共通に使い、結果を切り替えても保持する。旧版の保存データは1件の解析結果として引き継ぐ。

「保存データを削除」または「振動を調整 → 解析結果を選んで削除」で、複数の解析結果を選択して削除する。選ばなかった結果は保持する。使用中の結果を削除した場合は、残った結果のうち最後に使用したものへ切り替える。すべての解析を削除した場合だけ、その曲の履歴・調整値・保存音源も削除する。1曲の解析結果は最大200件。

アプリ側の削除はiPhoneの保存分が対象。PCの保存分は「解析方法・PCサーバー」の一覧で別に削除する。PCから削除しても、iPhoneに取り込んだ比較用の解析結果は保持する。

## 入力と保存

| 入力 | 作成時 | 再生時 |
| --- | --- | --- |
| YouTube動画 | PCでyt-dlpによる一時取得とAI解析。一時音源は削除 | 公式埋め込みプレーヤーと保存した振動 |
| 直接HTTPS URL | iPhoneで一時取得し、PCへ送って解析。一時音源は削除 | 元URLのストリーミングと保存した振動 |
| 保存済みファイル | 作り直しで手持ちの音源をPCへ送って解析 | 保存した音源と振動 |

音源は20分・512 MiB以内。YouTubeの一時取得は公式APIではなく、対象動画やサービスの変更で失敗する場合がある。その場合は同じ音源ファイルを指定して作成できる。通常の動画、短縮URL、Shorts、YouTube Musicの動画URLに対応する。署名付きの直接URLが失効した場合は新しいURLから追加する。HLS・ライブ配信は対象外。映像・音声だけ再生する選択肢もある。

PCには振動・解析グラフ・編曲スコア・AHAPを保存し、iPhoneには再生用の振動を保存する。AHAPは持続とアクセントを別ファイルへ書き出す。[レイヤーとAHAP](AHAP.md)。

## 検索・アカウント・削除

検索で動画・チャンネル・公開再生リストを表示する。チャンネルでは「動画」「再生リスト」を切り替え、「もっと読み込む」で続きを表示する。公開の検索にはGoogleログイン不要。

Googleログインすると自分のYouTube再生リストから選べる。50件ずつ取得する。YouTube全体の視聴履歴と「後で見る」は取得できない。「履歴」はこのアプリで再生した曲。[公式APIの変更履歴](https://developers.google.com/youtube/v3/revision_history#january-28,-2021)。

自動追加を有効にすると、追加権限を確認して非公開の「触感ラボ・振動作成済み」を作成する。保存できた動画だけを追加し、重複を避ける。失敗してもアプリ内の振動は保存し、「同期を再試行」で再送できる。同期が有効な間は、アプリで削除した曲を専用リストからも外す。

各曲の「… → 保存データを削除」で振動・調整値・アプリ内履歴・音源のアプリ内コピーを削除する。PC側の保存データはPC設定から別途削除する。外部の元音源とYouTube動画は保持する。

OAuth未設定のビルドではGoogleログインを利用できない。[Google設定](GOOGLE-LOGIN.md)。未設定でも動画検索・振動作成・アプリ内リストは利用できる。

## 再生同期

音楽の再生時刻を基準に短い振動区間を予約し、持続とアクセントを独立したCore Hapticsプレーヤーで再生する。一時停止・シーク・読み込み待ち・中断で止め、再開時に同期を取り直す。

YouTubeとネイティブ音源は再生位置を20 msごとに確認する。YouTubeの報告時刻の精度、広告、通信遅延、Bluetoothの影響はiPhone実機で確認が必要。Bluetooth等で音が遅れる場合は「同期の補正」で振動を遅くする方向へ調整できる。

動画の長さと解析データの長さが一致しない間は振動を待機する。許容差は1秒と解析時間の1.5%の大きい方。読み込み中・長さ未確定・別動画の通知は位置や長さを上書きしない。同じ長さで内容や開始位置が違う音源は自動判別できない。

再生画面の最小化とタブ切り替えでは再生を続ける。画面ロック、別アプリへの移動、振動ツールを開く操作では停止する。右上のメニューから振動サンプル、調整、タッチパッド、使い方を開ける。
