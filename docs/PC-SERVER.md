# PCで音楽を解析する

音楽プレイヤー2.1は初回に「このiPhone」「PCで精密解析」を選べます。作成後は振動をiPhoneにも保存し、PCを閉じても再生できます。前のUIのIPAは `dist/archive/2.0.0/`、ソースは `codex/music-haptics` ブランチへ残しています。

| 作り方 | 内容 | 利用場所 |
| --- | --- | --- |
| 音に追従 | 低音・音量・打音を振動へ変換 | iPhone / PC |
| リズム中心 | 推定テンポからアクセント・休符・控えめな持続を構成 | iPhone / PC |

「仕上げ」で「オーケストラ向け」を選ぶと、固定テンポの打点を加えず、元の強弱・自然な打音の位置を保って持続振動をなめらかにします。タップは強い打音だけに絞ります。「標準」に戻すと通常の作り方になります。音楽AIは後の更新で扱い、今回の版では使いません。

PCは44.1 kHz、4096点の低音FFT、1024点の打音FFT、10 ms間隔で解析します。iPhoneは22.05 kHz、1024点FFT、20 ms間隔です。PCの低音の分解能と時間間隔は細かくなります。触感の良さは実機で比較してください。

## Windowsで起動

Node.jsと [uv](https://docs.astral.sh/uv/getting-started/installation/) が必要です。ソースを展開したフォルダーのPowerShellで実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\pc-server\Start-PCServer.ps1 -Lan
```

初回はPython・解析ライブラリを取得します。設定後のファイル解析はPC内で動き、YouTube取得には通信が必要です。GPUは不要です。

1. iPhoneとPCを同じWi-Fiに接続します。
2. アプリ右上「…」→「解析方法・PCサーバー」を開きます。
3. `.pc-server/connection.json` の `addresses` にあるPCのURLと `token` の接続キーを入力し、「接続を確認」を押します。
4. 曲の初回画面で解析場所と作り方を選びます。

接続できない場合は、WindowsのプライベートネットワークでこのPythonサーバーを許可し、iPhoneのアプリ設定からローカルネットワークをオンにします。接続キーはGoogle認証とは別です。

## 取得・保存・削除

PC方式は [yt-dlp](https://github.com/yt-dlp/yt-dlp) でYouTubeの音源を一時取得し、解析後に削除します。取得できる公開動画が対象です。公式APIの機能ではなく、動画の制限やYouTube側の変更で失敗することがあります。

iPhoneだけでYouTube用の振動を作る場合は、同じ内容・開始位置の音源ファイルか、音声を直接返すHTTPSダウンロードURLを選びます。変換サイトのページを自動操作する機能はありません。

PCは振動を保存してiPhoneへ転送します。次回の映像・音声は元のプレーヤーから再生し、振動は端末の保存データを使います。曲の「…」→「振動を作り直す」で方式を変更できます。失敗時も前の保存データを維持します。

端末の個別削除に加え、「解析方法・PCサーバー」→「接続を確認」の下でPCの保存データを1曲ずつ削除できます。PCから削除しても端末の振動は残ります。ログは `.pc-server/server.log` と `.pc-server/data/working/<解析ID>/worker.log`、保存データは `.pc-server/data/tracks/` にあります。これらはGit・ソースZIPから除外します。

## 時間と表示

解析中は経過秒数と残り時間の目安を表示します。通信速度・曲の長さ・CPUによって変わります。SE3実機の所要時間は未計測です。測定結果は検証記録に記載します。

縦画面の下には振動の波形と再生バーを表示します。「周波数」は保存した振動の強弱をフーリエ変換した0.4〜25 Hzの表示です。音声の周波数やモーターの実測周波数ではありません。
